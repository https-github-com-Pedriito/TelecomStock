📱 Installation du certificat SSL pour mobile

⚠️ Important : Ce certificat est nécessaire pour accéder à l'application TelecomStock depuis votre mobile en HTTPS.
📥 Télécharger le certificat
📋 Instructions d'installation :

Pour Android :

  1. Téléchargez le certificat en cliquant sur le bouton ci-dessus
  2. Ouvrez Paramètres → Sécurité
  3. Recherchez Certificats de confiance ou Installer depuis le stockage
  4. Sélectionnez le fichier mkcert-ca-certificate.pem
  5. Donnez-lui un nom (ex: "TelecomStock Dev")
  6. Confirmez l'installation

Pour iOS :

  1. Téléchargez le certificat en cliquant sur le bouton ci-dessus
  2. Ouvrez Réglages → Général
  3. Tapez sur Profil ou Profils et gestion des appareils
  4. Sélectionnez le profil du certificat téléchargé
  5. Tapez sur Installer (en haut à droite)
  6. Entrez votre code de déverrouillage si demandé
  7. Allez dans Réglages → Général → Informations → Réglages des certificats
  8. Activez le certificat mkcert dans la liste
🔒 Sécurité : Ce certificat est généré localement sur votre machine de développement. Ne l'utilisez que pour le développement local.

Une fois le certificat installé, vous pourrez accéder à l'application via :
https://192.168.1.66:5173 ou https://192.168.1.66 (via Nginx)
