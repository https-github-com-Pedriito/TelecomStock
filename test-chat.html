🤖 Test de l'Assistant IA - TelecomStock

À quoi ressemble le bouton du chat :

Position : Bas à droite de l'écran
Taille : 56x56 pixels
Couleur : Bleu dégradé avec point vert

ℹ️ Important : Le bouton n'apparaît que si vous êtes connecté à TelecomStock.

Tests de connectivité

Checklist de vérification

  • ✅ Êtes-vous connecté à TelecomStock ? (pas sur l'écran de login)
  • ✅ Avez-vous actualisé la page avec Ctrl+F5 ?
  • ✅ Le frontend a-t-il fini de rebuilder ? (vérifiez les logs Docker)
  • ✅ Regardez-vous en bas à droite de l'écran ?
  • ✅ Essayez de zoomer/dézoomer (Ctrl + / Ctrl -)

Commandes utiles

# Voir les logs du frontend
docker logs telecomstock_frontend --tail 50

# Redémarrer le frontend
cd docker
docker compose restart frontend

# Reconstruire complètement
docker compose down
docker compose up -d --build
